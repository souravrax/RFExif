Generated with built-in ImageGen for RF EXIF. Transparent 4×4 sprite sheets. Camera row-major order is in web/src/lib/generated-equipment.json; expanded lens assignments and manufacturer sources are in web/lenses/inventory.json. The web runtime uses the smaller web/src/lib/generated-lenses.json. Illustrative silhouettes, not accurate product photographs. Camera selection has 16 bodies, mostly DIGIC X; EOS R, RP and R100 are also included. Expanded lens selection has 196 distinct models across 12 brands, including the RF-S18–150mm. This is a verified lower bound, not the complete global RF catalog.

Final prompts, including layout repair prompts, are saved in generation-prompts.json. Sheets 05 and 13 use the v2 assets. In sheet 13 only the first four cells add new models; the remaining twelve repeat existing Canon illustrations to keep generation spacing consistent and are not mapped or counted as new lenses. Earlier layout variants are retained for reference. UI sprites are loaded only when the matching equipment card is shown, not all at page load.

Individual named PNG cutouts now live in `individual/cameras/` and `individual/lenses/`, with repeated illustrations separated into `individual/duplicates/`. Run `web/scripts/split-equipment-sheets.py` to rebuild them. See `individual/README.md` for commands and crop limitations; `individual/manifest.json` maps each output to its source cell.
