# RF EXIF

Lettering-only wordmark using Google Fonts Anton, with tight custom spacing.
SVG lettering is outlined so it renders consistently without a font download.
The pink RF favicon uses the same lettering. Light and dark wordmarks are included.

Regenerate with Python and fonttools: `python web/scripts/build-brand.py`.
Font license: `web/static/fonts/anton-OFL.txt`.

Positioning: Free camera and lens insights for Canon EOS R.
RF EXIF is an independent tool for Canon photographers.
The existing GitHub repository and deployment base path are retained.
